## 📝 Prompt สำหรับการสร้างข้อความ (Text Generation)

### กรณีศึกษา 1: ร้านขายต้นไม้ "Greenery Home"

**1. [การปฏิบัติการ] ออกแบบขั้นตอนการทำงาน**
```
ในฐานะ "ที่ปรึกษาด้านการปรับปรุงกระบวนการทำงาน (Process Improvement Consultant)" จงช่วยออกแบบ Workflow สำหรับร้าน "Greenery Home"

โดยให้ "แสดงขั้นตอนออกมาเป็นลำดับอย่างละเอียด (step-by-step)" ตั้งแต่:
1.  การรับออเดอร์และยืนยันการชำระเงิน
2.  การเลือกและเตรียมต้นไม้ (การเช็คสภาพ)
3.  ขั้นตอนการแพ็กต้นไม้อย่างปลอดภัย
4.  การประสานงานกับบริษัทขนส่ง
5.  การแจ้งเลขพัสดุให้ลูกค้าทราบ
```

**4. [บริการลูกค้า] สร้างมาตรฐานการรับมือข้อร้องเรียน**
```
ในฐานะ "ผู้จัดการฝ่ายบริการลูกค้า" จงสร้างข้อความมาตรฐาน (Template) สำหรับตอบกลับลูกค้าทางแชท เมื่อลูกค้าแจ้งว่า "ต้นไม้ที่ได้รับมีใบหัก/ช้ำจากการขนส่ง"

โดยข้อความตอบกลับต้องประกอบด้วย:
1.  การกล่าวขอโทษและแสดงความเข้าใจ
2.  การขอข้อมูลเพิ่มเติม (เช่น รูปถ่าย)
3.  การเสนอทางแก้ไขปัญหา (เช่น การส่งต้นใหม่, ส่วนลดครั้งถัดไป)
4.  การให้ความมั่นใจกับลูกค้า
```

**5. [พัฒนาผลิตภัณฑ์] หาต้นไม้ใหม่เข้าร้าน**
```
จงค้นหาและเสนอชื่อ "ต้นไม้ในร่ม" (Indoor Plants) ที่มีคุณสมบัติตรงตามนี้มา 5 ชนิด:
- ดูแลง่ายมาก ทนทานเป็นพิเศษ
- ไม่ต้องการแสงแดดจัด สามารถอยู่ในคอนโดได้
- เป็นที่นิยมในตลาดปัจจุบัน

สำหรับแต่ละชนิด ให้บอกเหตุผลสั้นๆ ว่าทำไมถึงเหมาะกับลูกค้ามือใหม่ของร้าน "Greenery Home"
```

**6. [การขาย] เทคนิคการขายพ่วง (Upselling)**
```
ช่วยคิดประโยคสำหรับพนักงานขาย (หรือสำหรับระบบในเว็บไซต์) เพื่อใช้เสนอขายพ่วง (Upsell) ให้กับลูกค้าที่กำลังจะซื้อ "ต้นมอนสเตอร่า"

โดยให้เสนอ "ชุดปลูกต้นไม้ DIY" เป็นสินค้าเพิ่มเติม พร้อมบอกประโยชน์สั้นๆ ว่า "จะช่วยให้การย้ายกระถางในอนาคตเป็นเรื่องง่ายสำหรับมือใหม่" เสนอมา 2-3 รูปแบบประโยค
```

**7. [กลยุทธ์] การวิเคราะห์ภาพรวมธุรกิจ (SWOT)**
```
ในฐานะ "นักวิเคราะห์กลยุทธ์ธุรกิจ (Business Strategy Analyst)" ช่วยวิเคราะห์ SWOT Analysis สำหรับธุรกิจของฉันหน่อย โดยมีข้อมูลสรุปดังนี้:

- **ธุรกิจของฉันคือ:** ร้าน "Greenery Home" ขายต้นไม้ออนไลน์สำหรับมือใหม่
- **สินค้าหลัก:** ต้นมอนสเตอร่า, ต้นยางอินเดีย, ชุดปลูก DIY
- **จุดแข็งที่สุด (USP):** เรามีคู่มือดูแลที่เข้าใจง่าย และมีบริการให้คำปรึกษาฟรีทาง LINE
- **กลุ่มลูกค้าหลัก:** คนที่อาศัยในคอนโด, พนักงานออฟฟิศที่ไม่มีเวลา และกลัวทำต้นไม้ตาย
- **ช่องทางหลัก:** Facebook และการบอกต่อ

จากข้อมูลสรุปข้างต้น จงทำการวิเคราะห์ SWOT Analysis โดยให้ระบุ:
- Strengths (จุดแข็ง)
- Weaknesses (จุดอ่อน)
- Opportunities (โอกาส)
- Threats (อุปสรรค)
```

**8. [การปฏิบัติการ] พัฒนาประสบการณ์ลูกค้า (ฉบับปรับปรุง)**
```
ในฐานะ "ผู้เชี่ยวชาญด้านการออกแบบประสบการณ์ลูกค้า (Customer Experience Designer)" ช่วยเสนอไอเดียในการปรับปรุงขั้นตอน 'การส่งมอบ' ของธุรกิจฉันให้ดีขึ้น เพื่อสร้างความประทับใจและสะท้อนความเป็นมืออาชีพ

ข้อมูลธุรกิจของฉัน:
- **ธุรกิจของฉันคือ:** ร้านขายต้นไม้ออนไลน์ "Greenery Home"
- **ขั้นตอนการส่งมอบปัจจุบันคือ:** ลูกค้าได้รับกล่องพัสดุที่มีต้นไม้และใบเสร็จอยู่ข้างใน
- **สิ่งที่อยากปรับปรุง:** 1. ทำให้การเปิดกล่องน่าประทับใจขึ้น (Unboxing Experience) 2. ให้ข้อมูลการดูแลที่ชัดเจนและดูใส่ใจกว่าเดิม

จากข้อมูลนี้ จงเสนอไอเดียที่ทำได้จริงมา 3-5 ไอเดีย
```

**9. [ธุรการ] การเขียนอีเมลธุรกิจ**
```
ในฐานะเจ้าของร้าน "Greenery Home" จงช่วยร่างอีเมลธุรกิจเพื่อส่งถึงบริษัท "พอทเทอรี่ดีไซน์"

วัตถุประสงค์: เพื่อแนะนำตัว, สอบถามเกี่ยวกับการสั่งซื้อกระถางเซรามิกในราคาส่ง, และขอแคตตาล็อกสินค้า
โทนของอีเมล: สุภาพและเป็นมืออาชีพ
```

### 🌐 1. Prompts ในการหาไอเดียเพื่อสร้างธุรกิจ 🌐

* `"สร้างรายการไอเดียธุรกิจนวัตกรรม 10 อย่างในภาค [ระบุอุตสาหกรรม]"`
* `"แนะนำตลาดเฉพาะกลุ่ม (niche market) 3 แห่งภายใน [ระบุอุตสาหกรรม] ที่มีศักยภาพในการเติบโต"`
* `"ระบุแนวโน้มปัจจุบัน 5 ประการใน [ระบุอุตสาหกรรม] และวิธีที่ธุรกิจใหม่จะสามารถใช้ประโยชน์จากแนวโน้มเหล่านั้นได้"`
* `"วิเคราะห์คู่แข่งชั้นนำ 3 รายใน [ระบุอุตสาหกรรม] และแนะนำจุดขายที่ไม่เหมือนใคร (unique selling points) สำหรับธุรกิจใหม่"`
* `"เสนอไอเดียธุรกิจ 5 อย่างที่เน้นความยั่งยืนและผลกระทบต่อสังคม"`
* `"สร้างรายการไอเดียธุรกิจต้นทุนต่ำ 10 อย่างที่สามารถเริ่มต้นได้ด้วยเงินลงทุนน้อยที่สุด"`
* `"แนะนำไอเดียธุรกิจ 3 อย่างที่ตอบสนองตลาดการทำงานทางไกล (remote work) และฟรีแลนซ์"`
* `"ระบุโอกาสทางธุรกิจ 5 ประการที่เกิดขึ้นจากความก้าวหน้าทางเทคโนโลยีล่าสุด"`
* `"เสนอไอเดียธุรกิจ 3 อย่างที่สามารถช่วยแก้ปัญหาทั่วไปที่เจ้าของธุรกิจขนาดเล็กต้องเผชิญ"`
* `"บอกไอเดียธุรกิจ 5 อย่างที่สามารถใช้ประโยชน์จากความนิยมที่เพิ่มขึ้นของการช็อปปิ้งออนไลน์"`

### 🌐 2. Prompts ช่วยบริหารเวลา และจัดการชีวิต 🌐

* `"แนะนำเครื่องมือเพิ่มประสิทธิภาพ (productivity tools) 5 อย่างที่สามารถช่วยให้งานธุรกิจประจำวันของฉันราบรื่นขึ้น"`
* `"บอกกลยุทธ์ 3 ข้อในการบริหารจัดการเวลาอย่างมีประสิทธิภาพสำหรับเจ้าของธุรกิจขนาดเล็ก"`
* `"ระบุเทคนิค 5 อย่างเพื่อปรับปรุงสมาธิและลดสิ่งรบกวนขณะทำงาน"`
* `"เสนอกิจวัตรประจำวันสำหรับผู้ประกอบการเพื่อเพิ่มผลิตภาพให้สูงสุด"`
* `"แนะนำวิธีการจัดลำดับความสำคัญและจัดระเบียบงานสำหรับธุรกิจของฉัน 3 วิธี"`

* `"แนะนำวิธีการให้ข้อเสนอแนะเชิงสร้างสรรค์ (constructive feedback) แก่สมาชิกในทีม 3 วิธี"`

### 🌐 4. Prompts ช่วยเขียนอีเมลทางธุรกิจ 🌐

* `"เขียนอีเมลแนะนำธุรกิจใหม่อย่างเป็นทางการถึงลูกค้าเป้าหมาย"`
